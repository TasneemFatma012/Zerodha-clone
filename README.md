# 📈 Zerodha Clone — Smart Investing Platform

**A modern trading experience, built from the ground up.**

A full-stack **Zerodha-inspired investment platform** designed to recreate the core experience of a modern trading application with a clean interface, interactive market dashboard, and portfolio management features.

The project combines a **responsive frontend with RESTful backend APIs** to create a realistic workflow for exploring markets, managing investments, placing orders, and tracking portfolio performance.

### ✨ Platform Features

* 📊 **Market Dashboard** — View stocks and market information in one place
* 👀 **Watchlist** — Track stocks you're interested in
* 💼 **Holdings** — Monitor your investment portfolio
* 🛒 **Order Management** — Simulate buy and sell orders
* 💰 **Funds Management** — Track available trading balance
* 📈 **Portfolio Analytics** — Get a visual overview of investments
* 🪪 **KYC Management** — Handle user verification details
* 🔐 **Authentication** — Secure user login and session-based access
* 📱 **Responsive UI** — Designed for a smooth experience across screen sizes

### 🛠️ Tech Stack

**Frontend:** React.js, Vite, MUI
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Communication:** Axios, REST APIs

### 🎯 Project Objective

The goal was to go beyond simply copying a UI and understand how a **real-world trading platform is structured** — from frontend components and API communication to database operations, authentication, orders, holdings, and funds.

> **Build the interface. Understand the system. Think like a product engineer. 🚀**
